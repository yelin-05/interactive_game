## 关键决策（别再重复讨论）

- 框架：**Spring Boot 3.3.5 + MyBatis-Plus 3.5.9 + Thymeleaf**，`java.version=21`
- 数据库：**MySQL 9.7 为主（profile `mysql`，默认）+ H2 内存（profile `h2`）**，靠 profile 切换
- MySQL 驱动锁 **9.1.0**（Boot 默认的 8.3.0 连不上 9.x 服务端），连接串必须带 `allowPublicKeyRetrieval=true&useSSL=false`
- 建表：`db/schema-mysql.sql` 全是 `CREATE TABLE IF NOT EXISTS`，启动时执行，不清数据
- 题库：存 `t_question`，选项用 `options_json`（JSON 数组），不放 option_a~d 四列
- 题库种子：`resources/seed/questions.json` + `QuestionSeeder`（表空才灌，幂等）。
  这样一份数据同时喂 MySQL 和 H2，不用维护两套 INSERT
- 游戏模板：**已选 C 知识闯关**，A/B 保留未删
- **已知问题**：`/api/quiz/questions` 会把 `answerIndex` 下发前端，前端自行判题 →
  可作弊。做排行榜前必须改成服务端判题

## 踩过的坑（别重犯）

1. **PATH 里的 `java` 是 Oracle JRE 1.8**，跑 jar 要用 `$env:JAVA_HOME\bin\java.exe`，否则 `UnsupportedClassVersionError`
2. **MySQL 是 9.7 不是 8.x**，驱动和连接参数按上面配
3. **PowerShell 传 `-Dfile.encoding=UTF-8` 会被拆坏**，Maven 参数别带这个；含中文的命令串也容易被吃掉引号，脚本里尽量用纯 ASCII
4. **headless 浏览器截图**在 DSH 沙箱下会因命名管道受限失败，需要提权；且输出路径不能含空格（会被 `--screenshot=` 拆成多个参数）
5. **`~/.m2/settings.xml`** 已配阿里云镜像（原文件有 `.bak` 备份）
