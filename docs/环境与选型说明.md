## 二、两个环境坑（已处理）

### 1. `java` 与 `javac` 版本不一致

```
java   -> Oracle JRE 1.8      （错，会报 UnsupportedClassVersionError）
javac  -> D:\java\JDK_21\bin  （对）
JAVA_HOME -> D:\java\JDK_21   （对）
```

Maven 与 IDEA **都以 `JAVA_HOME` 为准**，所以命令行构建没问题；
但 `java -jar` 跑打包产物时会踩到 JRE 8。解决方式（二选一）：

- 临时：`& "$env:JAVA_HOME\bin\java.exe" -jar target\minigame-asset-0.1.0-SNAPSHOT.jar`
- 长期：把 `%JAVA_HOME%\bin` 移到 PATH 最前面，或卸载 Oracle JRE 8 的 shim

### 2. MySQL 是 9.x，不是 8.x

Spring Boot 3.3.5 默认管理的驱动是 `mysql-connector-j:8.3.0`，
连 9.x 服务端可能握手失败。因此 `pom.xml` 里显式锁定：

```xml
<mysql.version>9.1.0</mysql.version>
```

同时 MySQL 9 已彻底移除 `mysql_native_password` 插件，账号认证只能用
`caching_sha2_password`（默认），连接串因此必须带：

```
allowPublicKeyRetrieval=true&useSSL=false
```

否则会报 `Public Key Retrieval is not allowed`。

## 三、技术选型理由（答辩可直接讲）

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Spring Boot 3.3.5 | 内嵌 Tomcat，`java -jar` 一条命令启动，答辩现场不用装/配容器；仍属 Jakarta EE 生态 |
| 持久层 | MyBatis-Plus 3.5.9 | 单表 CRUD 零 SQL，分页插件直接拿到 `total`；排行榜/素材库列表省大量样板代码；比 JPA 更贴近课程里的 SQL 教学 |
| 视图 | Thymeleaf | 服务端渲染 + 天然防 XSS；页面不引 CDN，断网可演示 |
| 主库 | MySQL 9.7 | 本机已装且已运行，评分需要标准 SQL 建表脚本 |
| 演示库 | H2 内存（MySQL 模式） | GitHub 上别人 clone 即跑，CI 不需要 MySQL；`MODE=MySQL` 保证两套 SQL 语法接近 |
| 大模型 | Mock / Real 双通道 | 答辩现场网络不可控，默认 mock 保证演示不断；配了 Key 自动走真实接口 |
| 打包 | 可执行 jar | 比 WAR 少一层部署配置，`mvnw package` 后双击即跑 |

不用 JSP 的说明：JSP 需要外置 Tomcat 与 WAR 部署，现场调试成本高；
Thymeleaf 在功能上完全覆盖作业要求（服务端渲染、表单、列表遍历）。

## 四、双数据源设计

用 Spring Profile 隔离，代码零改动切换：

| Profile | 数据源 | 建表方式 | 用途 |
| --- | --- | --- | --- |
| `mysql`（默认） | MySQL 9.7 | 启动时执行 `db/schema-mysql.sql`（`CREATE TABLE IF NOT EXISTS`，不清数据） | 正式运行、评分 |
| `h2` | H2 内存（MySQL 兼容模式） | 启动时执行 `db/schema-h2.sql` + `db/data-h2.sql`（每次重建） | 演示、单元测试、CI |

切换方式：

```powershell
mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=h2     # 演示档
mvnw.cmd spring-boot:run                                   # 默认 MySQL 档
```


VS Code 本身不认识 Java，需要扩展。已装 `vscjava.vscode-java-pack`（含
`redhat.java` 语言服务器、调试器、测试运行器、Maven 支持）。

仓库里已提交 `.vscode/` 四个配置文件：

| 文件 | 关键作用 |
| --- | --- |
| `settings.json` | `java.jdt.ls.java.home` 指向 `D:\java\JDK_21`；`maven.executable.preferMavenWrapper=true` 让构建走 `mvnw`，不依赖本机装 Maven |
| `launch.json` | `F5` 启动：`启动 · H2 演示档` / `启动 · MySQL 正式档`，支持断点 |
| `tasks.json` | `mvn: 编译 / 打包 / 跑测试`、`run: H2 演示档` |
| `extensions.json` | 打开项目时推荐安装 Java 与 Spring Boot 扩展 |

首次打开项目，红帽语言服务器要导入 Maven 模型，右下角显示
`Java: Importing…`，约 1-3 分钟；导入完成后左侧会出现 `JAVA PROJECTS` 面板。
