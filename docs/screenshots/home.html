这个项目是什么

「魔识」是一个互动答题平台：用户在五个知识分区（计算机 / 文学 / 地理 / 历史 / 科学）里 按难度档位答题，交卷后由服务端判分，成绩入库并进入排行榜； 完成指定局数可以领取任务奖励；管理员可以在后台查看运营数据。

技术栈：JavaEE 8（javax.servlet.*）+ Tomcat 9 + JSP/JSTL + 原生 JDBC + MySQL 8。 账号由部署者初始化，页面不公开任何固定密码。
